# Kuis Family 100 - Bimbel Golden Kids 🌟

Game web interaktif bertema Family 100 untuk kegiatan belajar & kuis di Bimbel Golden Kids.

## Fitur
- Papan skor interaktif untuk 2 tim
- Kartu jawaban dengan animasi flip dan efek suara
- Sistem strike / salah
- Tampilan responsif dan ramah untuk layar sentuh / proyektor
